# Práce týmu

Tato složka obsahuje všechno, co musí udělat a zapsat **lidé z týmu**, ne AI. Pro každou iteraci je tu jeden soubor s úkoly a jeden kontrolní list.

| Iterace                            | Úkoly týmu                         | Kontrolní list                                       | Stav         |
| ---------------------------------- | ---------------------------------- | ---------------------------------------------------- | ------------ |
| 1 – specifikace a data (cvičení 2) | [iteration-01.md](iteration-01.md) | [controls/iteration-01.md](controls/iteration-01.md) | rozpracováno |

## Jak se složka používá

1. AI po každé iteraci zapíše, co udělala a co zkontrolovala strojově, do `docs/ai-usage/iteration-0N.md`.
2. Tým projde kontrolní list v `controls/` a ke každé kontrole zapíše, kdo ji provedl, kdy a s jakým výsledkem.
3. Tým vyplní soubor úkolů: co z návrhů AI přijal, upravil a odmítl a jaké chyby našel.
4. Výsledky se přenesou do odevzdávaných souborů (specifikace, `progress-0N.md`, prezentace).
